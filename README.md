## Getting started: a practical workflow

1. Download the Windows archive below and extract it to a normal folder.
2. Open the application and create a build profile named after the playstyle you want to test.
3. Record the two main weapons, the Phantom Edges and the accessory plan.
4. Test the loadout in a repeatable encounter, noting control, recovery time and any trade-offs.
5. Compare profiles before replacing an in-game setup. Keep the game version next to your notes.

**A sensible testing method:** compare builds on the same enemy or encounter, difficulty, weapon upgrade level and consumable setup. A result from a highly polished endgame item is not directly comparable to a fresh weapon. Treat ranking pages as reference points, not guarantees.
